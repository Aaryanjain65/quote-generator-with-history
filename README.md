# Quote Generator with History

A full-stack application to generate random inspirational quotes and manage favorites.

## Features
- Random quote generation
- DummyJSON API integration
- SQLite fallback quotes
- Add and remove favorites
- Favorite history
- Copy quotes

## Technologies
- React.js and Vite
- Node.js and Express.js
- SQLite and better-sqlite3

## Project Structure
- client/ - React frontend
- server/ - Node.js backend
- server/database/ - SQLite database
- server/data/ - Fallback quote data

## Run Project
Backend: cd server; npm install; node server.js
Frontend: cd client; npm install; npm run dev
