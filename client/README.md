# Quote Generator with History

A full-stack web application that generates random inspirational quotes and allows users to save and manage their favorite quotes.

## Features

- Generate random quotes
- Fetch quotes from DummyJSON API
- SQLite fallback when API is unavailable
- Save favorite quotes
- View favorite history
- Remove favorite quotes
- Copy quotes to clipboard
- Responsive user interface

## Technologies Used

### Frontend
- React.js
- Vite
- CSS

### Backend
- Node.js
- Express.js
- SQLite
- better-sqlite3

### API
- DummyJSON Quotes API

## Project Structure

- client/ - React frontend
- server/ - Node.js backend
- server/database/ - SQLite database
- server/data/ - Fallback quote data
